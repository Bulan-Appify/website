Cookie notice

Short version: this website sets no tracking cookies, loads no third-party fonts, no advertising pixels and no social media trackers. That is why you did not get a consent banner.

Last updated: [date you publish this]

No consent banner, because there is nothing to consent to. We would rather build a site that does not need one than build one that nags you into clicking "accept all".

What this site does not do

  • No analytics or tracking cookies
  • No advertising or remarketing pixels — no Meta pixel, no Google Ads tag, no LinkedIn Insight tag
  • No third-party fonts. Typography uses fonts already on your device, so nothing is requested from an external font server
  • No embedded chat widget, video player or map that would load code from another company
  • No cross-site tracking of any kind
  • No fingerprinting

What it does do

MechanismPurposeStored?
Server logsOur hosting provider records IP address, user-agent, requested page and timestamp as a normal part of serving pages and protecting the site from abuse.On the host's servers, for their standard retention period

Form submissions

When you submit the contact form or generate a quotation, the details you entered are sent to us so we can reply. That is described in the privacy notice. It is not cookie-based and it only happens when you deliberately submit.

If we add analytics later

We may eventually want to know which pages people find useful. If we do, the commitment is:

  • We will use a privacy-friendly, cookieless analytics tool that does not track individuals across sites
  • We will name the tool on this page before it goes live
  • We will not add advertising trackers, session recording or heat-mapping tools that capture what you type
  • If any tool we add requires consent under POPIA, you will be asked properly — with a real choice, and with refusing as easy as accepting

Managing cookies in general

Every major browser lets you view, block and delete cookies through its settings. Since this site sets none, doing so will not affect how it works. It is still worth knowing how, for the rest of the web.

Questions

Email privacy@bulan.co.za. If you check this page and find that it no longer matches what the site actually loads, tell us — that would be a mistake on our part and we would want to fix it quickly.

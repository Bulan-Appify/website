The honest version

Anyone can ship version one.

The expensive part of software is not the first release. It is month eighteen, when the original developer has moved on, nobody wrote anything down, the test suite was abandoned at 11% coverage and a two-line change takes three weeks because everyone is afraid of it.

We build for that month. Readable code, documented decisions, automated tests that actually run, infrastructure defined in version control, and a handover pack written for a stranger. It costs slightly more on day one and dramatically less over the life of the system.
